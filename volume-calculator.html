What this calculator estimates

Calculate rectangular-prism, cylinder and sphere volumes from editable dimensions.

How to use it

Enter Box length; Box width; Box or cylinder height; Cylinder or sphere radius. Select Calculate to update the results.

How the calculation works

The calculator applies standard geometric formulas for a rectangular prism, cylinder and sphere.

Worked example: starting scenario

Box length10

Box or cylinder height4

Important limitations

All dimensions must use the same unit. Results are mathematical estimates and do not include material waste.

Each shape uses different dimensions

The box uses length, width and height; the cylinder uses radius and height; the sphere uses radius alone. With radius 3 and height 4, cylinder volume is 36π, while sphere volume is also 36π for this particular radius. The equality is coincidental. Use a radius rather than a diameter and one consistent length unit; all volume outputs use cubic units.
