What this calculator estimates

Estimate expected gross profit per lead, total lead value and net acquisition return from close rate, sale value, margin and cost per lead.

How to use it

Enter Average sale or contract value ($); Gross margin (%); Lead-to-customer close rate (%); Number of leads; Acquisition cost per lead ($). Select Calculate to update the results.

How the calculation works

Gross profit per sale is average sale value multiplied by gross margin. That amount is multiplied by close rate to estimate expected gross profit value per lead.

Important limitations

Lead quality, sales capacity, repeat revenue, refunds, churn, overhead and attribution can change realized value.
