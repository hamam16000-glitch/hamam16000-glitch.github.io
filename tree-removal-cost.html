What this calculator estimates

Estimate tree removal cost using tree count, average height, base price, hazard factor, stump grinding, debris hauling and permits.

How to use it

Enter Number of trees; Average tree height (ft); Base removal cost per 50-ft tree ($); Access and hazard factor; Stump grinding total ($); Debris hauling total ($); Permit and traffic-control cost ($). Select Calculate to update the results.

How the calculation works

Removal cost scales the base 50-foot price by tree height, count and an access or hazard factor. Stump, debris and permit costs are added.
