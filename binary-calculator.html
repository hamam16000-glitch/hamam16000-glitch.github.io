What this calculator estimates

Convert a whole decimal number to binary, hexadecimal and octal notation.

Inputs and units

Fill in each field, then select Calculate to update the results. Required fields cannot be blank.

  • Decimal whole number: the integer to convert, written in ordinary base ten. The converter accepts whole numbers only, not fractions, as the limitations note says; a leading minus sign is allowed.

Method and assumptions

The calculator reads the entry as an integer and rewrites the same value in base two, base sixteen and base eight, then counts the bits in the binary form. A negative entry keeps its minus sign and converts the magnitude.

With the starting input 255: the binary value is 11111111, the hexadecimal value is FF, the octal value is 377 and the bit length is 8.

Reading the result

  • Binary value is the base-two spelling of the same number; each digit is one bit.
  • Hexadecimal and Octal are the same value grouped by fours and threes of bits, which is why 11111111 lines up with FF and 377.
  • Bit length counts the binary digits; 255 is the largest value that fits in exactly 8 bits.

Common mistakes

  • Typing a decimal fraction like 2.5; the converter rejects it, because it accepts whole numbers only.
  • Typing letters other than a leading sign; entries like 1e3 or 0xFF are rejected rather than interpreted.
  • Reading the bit length as a byte count; 8 bits make one byte, and larger numbers need more bits.
  • Adding spaces or thousands separators; enter the plain digits only.

Frequently asked questions

What happens with a negative number?

The minus sign is kept and the magnitude is converted, so the output reads as a negative binary, hexadecimal and octal value rather than two's-complement form.

Why is there no fractional part?

That is the page's documented scope: whole decimal integers only. Convert the integer and fractional parts separately with other tools if you need fractional binary.

Is there a size limit?

The entry is handled as an arbitrary-length integer, but the field rejects entries longer than 4,096 digits; ordinary computing values fit easily.

Important limitations

This converter accepts whole decimal integers only, not decimal fractions.

Sign and representation

A decimal integer of 10 is 1010 in binary, A in hexadecimal and 12 in octal. Negative numbers are displayed with a minus sign followed by the magnitude: −10 becomes −1010. This is not a fixed-width two’s-complement encoding, and the bit count describes the magnitude rather than a machine word including a sign bit. Enter decimal digits only; binary prefixes, fractions and scientific notation are not accepted.
