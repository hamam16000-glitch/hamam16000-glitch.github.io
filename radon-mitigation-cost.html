What this calculator estimates

Estimate a radon-mitigation project cost from base system pricing, foundation zones, crawl-space work, electrical service, testing and permits.

Inputs and units

Fill in each field, then select Calculate to update the results. Required fields cannot be blank.

  • Base active mitigation system ($): the quoted price for the base system with one suction zone.
  • Foundation suction zones: how many suction zones the design calls for. The design comes from the contractor's assessment of your foundation, as the limitations note indicates.
  • Cost per zone beyond the first ($): the added cost for each zone past the first.
  • Crawl-space membrane work ($): the fixed amount for crawl-space membrane work, if the design includes it. The starting zero means none.
  • Electrical outlet and fan wiring ($): the fixed amount for the electrical work the fan needs.
  • Post-installation testing and monitor ($): the fixed amount for the post-installation test and any monitor.
  • Permits and inspection ($): the fixed permit and inspection total.

Method and assumptions

The model adds a per-zone cost for each zone beyond the first to the base system price, then adds crawl-space, electrical, testing and permit amounts. There is no contingency field. It also divides the total by the zone count for a per-zone figure.

With the starting inputs: a $1,500 base system plus one added zone at $500 gives $2,000.00, no crawl-space work, and electrical, testing and permits add $750.00, for a total of $2,750.00, or $1,375.00 per zone.

Reading the result

  • Base system and added zones is the line the zone count moves; each added zone adds its per-zone cost.
  • Crawl-space work is zero in the starting scenario; homes with crawl spaces add a real amount here.
  • Average cost per suction zone divides the total, including fixed electrical and testing costs, by the zone count.

Common mistakes

  • Choosing the zone count yourself; the contractor's design for your foundation type sets it.
  • Leaving crawl-space work at zero when the home has a crawl space the design must address.
  • Dropping the post-installation test to save money; the test is what confirms the system works.
  • Comparing the per-zone result to a bare base-system advertised price.

Frequently asked questions

Does this page tell me whether I need mitigation?

No. That answer comes from testing, which this page does not do. It prices the system design you enter.

Why no contingency field?

The model prices exactly the quoted scope: base system, added zones, and fixed electrical, testing and permit amounts. If a quote carries a buffer, it lives inside those quoted amounts.

Where does a warranty or service plan go?

Add its price to the permits and inspection field as a fixed amount if you want it in the total. What the warranty covers is a documents question; the limitations note lists contractor warranty as a factor.

Important limitations

Foundation type, number of zones, crawl spaces, routing, electrical access, local code, radon level and contractor warranty affect actual pricing.
