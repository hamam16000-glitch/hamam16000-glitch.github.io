What this calculator estimates

Estimate window replacement materials, installation labor, finishing, permits and contingency.

Inputs and units

Fill in each field, then select Calculate to update the results. Required fields cannot be blank.

  • Number of windows: how many windows are being replaced in the project. Count every opening that gets a new unit, including small bathrooms and basement windows.
  • Average window unit cost ($): the average price of one window unit itself, before installation. If quotes bundle unit and labor together, split them so each cost is entered exactly once.
  • Installation labor per window ($): the labor charge to install one window. Use the per-window labor line from a written quote, not the whole project's labor total.
  • Trim, disposal and finishing ($): the fixed amount for interior and exterior trim work, old-window disposal and finishing, but only when the per-window prices exclude them. If they are already in the unit or labor price, enter zero here.
  • Permit costs ($): the fixed permit or inspection fee for the whole project. Include it exactly once: here, or inside a bundled quote, never both.
  • Contingency (%): a percentage buffer applied to everything above. Use it for unknowns like hidden rot or frame repairs found after removal.

Method and assumptions

The model multiplies the window count by the unit cost and by the per-window labor, adds the fixed trim, disposal, finishing and permit amounts, then applies the contingency percentage to that subtotal. It also divides the total by the window count for an average installed cost per window.

With the starting inputs: 12 windows at $700 gives $8,400.00 in units, 12 at $250 gives $3,000.00 in labor, and the subtotal with $1,500 trim and $300 permits is $13,200. Contingency at 8 percent adds $1,056.00, for a total of $14,256.00, or $1,188.00 per window.

Reading the result

  • Window units and Installation labor scale with the window count; changing the count moves both lines together.
  • Contingency allowance is the percentage buffer on the whole subtotal, so it grows when any other line grows.
  • Average installed cost per window is the total divided by the count, including fixed costs, so small projects show a higher per-window figure than large ones with the same inputs.

Common mistakes

  • Entering a bundled quote (unit plus labor) as the unit cost while also filling the labor field, which counts installation twice.
  • Putting the whole project's labor total into the per-window labor field instead of dividing by the window count.
  • Forgetting that trim, disposal and permit amounts are fixed totals, not per-window prices.
  • Setting contingency to zero and then treating the result as a ceiling; the model adds nothing for hidden damage unless you budget it.

Frequently asked questions

Why is my per-window cost so high?

The average divides the total, including fixed trim, disposal and permit costs, by your window count. With few windows those fixed costs spread over less work. Check whether the per-window quotes you compare against include the same items.

Where do I put a lead-safe work surcharge?

If a quote lists it as a separate fixed charge, add it to the trim, disposal and finishing field. If it is priced per window, raise the per-window labor instead. Enter it exactly once.

Should the unit cost include the labor?

No. This calculator prices units and labor separately so you can see each line. If your quote bundles them, split the quote into its unit and labor parts before entering it.

Important limitations

Custom sizes, structural repairs, lead-safe work, historic requirements, glazing packages and access conditions can change pricing.
