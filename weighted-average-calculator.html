What this calculator estimates

Calculate a weighted average from four values and their corresponding weights.

Inputs and units

Fill in each field, then select Calculate to update the results. Required fields cannot be blank.

  • Value 1: the first value. It can be 0 or negative.
  • Weight 1: the first value's weight. It can be 0.
  • Value 2: the second value. It can be 0 or negative.
  • Weight 2: the second value's weight. It can be 0.
  • Value 3: the third value. It can be 0 or negative.
  • Weight 3: the third value's weight. It can be 0.
  • Value 4: the fourth value. It can be 0 or negative.
  • Weight 4: the fourth value's weight. It can be 0.

Method and assumptions

The calculator multiplies each value by its weight, totals the products, and divides by the total weight, which must be above zero. It also shows the total weight, the plain unweighted average, and the smallest and largest values.

With the illustrative starting inputs: the products total 8,850 over a weight of 100, so the weighted average is 88.5, against a plain average of 85, with values spanning 75 to 95.

Reading the result

  • The headline is the weighted average: 88.5 on the starting inputs.
  • The plain-average line (85) sits below it because the heavier weights land on the higher values here; the gap between the two lines is the weighting at work.
  • The result always stays inside the value span (75 to 95 on the starting inputs), so a headline outside the min-max lines means an entry is off.

Common mistakes

  • Entering percentages as decimals in the weight fields; the model only needs the weights to be in the same units as each other, since it divides by their total.
  • Leaving the total weight at zero; the division needs a positive total, and the form rejects an all-zero weight set.
  • Reading the plain average as the weighted one; the plain line (85) ignores the weights entirely, and only the headline (88.5) uses them.

Frequently asked questions

How is the weighted average computed?

Each value times its weight, totaled and divided by the total weight: 8,850 over 100, which is 88.5 on the starting inputs.

Do the weights need to sum to 100?

No. Any same-unit weights work, because the model divides by the actual total; 100 on the starting inputs just makes the check easy.

Why show the plain average?

For comparison: 85 unweighted against 88.5 weighted shows the effect of the entered weights directly.

Important limitations

Weights can use any consistent scale, but their total must be greater than zero.
