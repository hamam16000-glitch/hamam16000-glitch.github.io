What this calculator estimates

Calculate powers, roots, logarithms and trigonometric values from editable numbers and angles.

How to use it

Enter Number x; Exponent y; Angle in degrees. Select Calculate to update the results.

How the calculation works

The calculator uses standard JavaScript mathematical functions for exponents, square roots, base-10 logarithms and degree-based trigonometry.

Important limitations

Very large powers can exceed browser numeric limits. Trigonometric results are rounded floating-point estimates.

Absolute-value helpers and angle units

The power uses x and y as entered, but the root and common-log helper outputs explicitly use |x|. For x = −9, the helper root is √|−9| = 3; that is not a real square root of −9. The angle input is in degrees: at 90°, sine is approximately 1 and cosine approximately 0. A negative base with a noninteger exponent may have no real-valued result.
